7 / 7 · 我的结论

Fabric/Databricks/SQL 组合下的安全 Text-to-SQL 架构适合多租户企业数据 Agent 生产落地。

✅ Good fit
  • Enterprise BI and data agents needing identity pass-through and row-level controls
  • Read-only SQL sandboxing with AST policy checks before execution
  • Semantic metric layer grounding to reduce raw-schema hallucination risk
  • Cross-tenant exfiltration detection and hard-block governance
⛔ Not for
  • Direct free-form SQL execution without AST allowlist policy enforcement
  • Bypassing Entra OBO and using shared service identity for all tenants
  • Grounding on raw schema only, with no semantic metric layer constraints
  • Missing exfiltration guardrails for cross-workspace/tenant data routes
