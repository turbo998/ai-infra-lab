7 / 7 · 我的结论

Azure Local + Arc + APIM Hybrid 的主权边缘架构适合高合规多站点 Agent 生产部署。

✅ Good fit
  • Sovereign environments requiring local PII residency with controlled cloud escalation
  • Edge sites needing sub-50ms local tool execution during WAN instability
  • Store-and-forward state sync for semi-disconnected operations
  • Arc-enabled governance across distributed edge Kubernetes clusters
⛔ Not for
  • Routing sovereign PII directly to cloud without residency policy checks
  • Assuming always-on WAN and skipping edge queue replay design
  • No local fallback model/runtime for disconnected execution windows
  • Mixing tenant/state domains across edge and cloud sync channels
