7 / 7 · 我的结论

Hub-Spoke 私网落区 + NSP + DNS + Firewall 适合受监管 Agent 工具调用治理。

✅ Good fit
  • Coding Agent sandbox: private subnet injection with explicit egress allowlists
  • Browser/CUA cluster: managed VNet lane for low-ops private service access
  • Multi-tenant SaaS gateway: NSP segmentation with tenant-scoped egress policy contracts
  • Financial zero-trust: Firewall TLS/FQDN governance + immutable private DNS lineage
⛔ Not for
  • Public egress defaults with post-hoc deny rules
  • Single flat VNet without spoke isolation and route boundaries
  • No private DNS governance for agent tool endpoint resolution
  • Firewall policies without tenant-aware attribution and replay audit
