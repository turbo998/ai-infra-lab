7 / 7 · MY TAKE

Tiered disaggregated KV cache architecture fits multi-tenant long-context agent workloads.

✅ Good fit
  • Coding Agent sandbox: split prefill/decode to isolate burst traffic from interactive turns
  • Browser/CUA cluster: keep hot decode lane on low-latency local NVMe cache
  • Multi-tenant SaaS gateway: tenant-keyed KV cache partition + policy guardlane
  • Financial zero-trust: enforce storage/class-of-service boundaries with immutable cache lineage
⛔ Not for
  • Single shared KV cache namespace across tenants without partition tags
  • Mixing prefill/decode lanes under one auto-scaling policy for all workloads
  • No cache staleness TTL budget for long-context replay-heavy sessions
  • Ignoring network fabric difference between InfiniBand and RoCEv2 lanes
