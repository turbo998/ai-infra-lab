✅ Good fit
  • Agent PRs require deterministic quality/safety gate before production exposure
  • Tool-call trajectory evaluators track policy violations across multi-step runs
  • PyRIT adversarial suites and synthetic datasets are versioned in CI
  • Online production sampling closes the loop with rollback thresholds
⛔ Not for
  • Shipping model/tool changes without offline + red-team gate evidence
  • Using single-score evaluation without trajectory-level policy diagnostics
  • Ignoring online drift and relying only on pre-release benchmarks
  • Setting rollback policy after incidents instead of pre-defined thresholds
