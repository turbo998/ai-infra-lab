## 1. 执行结论
1. 航空生产级智能体必须把技术资料检索、维修执行集成、放行签署合规拆成独立控制平面。
2. 推荐采用三平面架构，并在检索与放行节点设置硬边界。
3. **平面 A**：Foundry + AI Search + Document Intelligence，按机号/尾号/构型效力严格过滤技术资料。
4. **平面 B**：AMOS/TRAX/IFS/SAP 通过 APIM + MCP 接入，承载工卡草拟、MEL 时限计算、AOG 库存联动。
5. **平面 C**：离线边缘执行 + Part-145 双签放行合规，承载 CRS 加密签署与不可篡改归档。
6. 禁止跨机队或跨效力块检索混入错误维修程序。
7. 禁止由概率模型自动关闭非例行工卡。
8. AOG 处置质量依赖确定性库存、时限规则与持证人员可用性。
9. 远端机坪网络不稳定时，仍须可访问经批准的离线资料包。
10. Certificate of Release to Service 必须保留人类持证放行权。

## 2. 范围与前提
### 2.1 覆盖范围
- eTechLog 与 ACARS 故障码接入，映射 ATA 100 / iSpec 2200 结构。
- AMM、FIM、IPC、TSM、MEL/CDL 等资料的故障排查支持。
- MEL A/B/C/D 延期时限确定性计算。
- 全球 AOG 可换件（rotable）库存联动与调拨支持。
- FAA Part 145 / EASA Part-145 / CAAC CCAR-145 下的 CRS 合规治理。
### 2.2 前提假设
- 机队元数据包含 MSN、尾号、构型效力与修订状态。
- MRO ERP 可通过安全 API 契约接入。
- B1/B2 或 A&P 等持证签署角色可参与放行流程。
- 机库与机坪平板可运行 Arc 管理下的离线缓存包。
### 2.3 强制边界
- 禁止输出来自过期修订版或错误效力块的指导。
- 禁止非例行工卡在无人检验签署情况下自动关闭。
- 禁止依赖纯云端资料访问导致远端机坪断连失能。
- 禁止未完成双签与归档就执行 CRS 放行。
- 禁止绕过工具校准与前置条件校验。

## 3. 方案 A：尾号/效力锁定技术资料 RAG 平面
### 3.1 核心价值
- 按 MSN、尾号、构型效力严格过滤检索范围。
- 将排故建议锚定到已批准 AMM/FIM/IPC/TSM/MEL 引文。
- 阻断 Boeing/Airbus 或修订状态交叉污染。
- 支持 S1000D/SGML/PDF 资料结构化解析。
- 提升“建议 -> 原文依据”可追溯性。
### 3.2 优势画像
- 在检索正确性与安全性方面能力最强。
- 显著降低错误程序引用风险。
- 提升航线技师资料查找效率。
### 3.3 局限性
- 依赖资料版本治理与效力元数据质量。
- 不能替代执行层与签署层治理。
- 解析链路需持续质量监控。
---
## 4. 方案 B：MRO ERP 与航线执行 MCP 平面
### 4.1 核心价值
- 通过 AMOS/TRAX/IFS/SAP 受控连接器统一执行入口。
- 输出结构化工卡草案并执行字段校验。
- 做 MEL 时限规则确定性计算并推送提醒。
- 校验工具校准状态与执行前置条件。
- 联动全球 AOG 可换件库存与调拨路径。
### 4.2 优势画像
- 在执行闭环和规则确定性方面能力最强。
- 有利于计划控制与航线执行协同。
- 能把建议变为可执行动作并保留审计轨迹。
### 4.3 局限性
- 多系统异构接入复杂度高。
- 字段级策略与权限映射工作量较大。
- 多航司并行时流程统一难度上升。
---
## 5. 方案 C：离线边缘与 Part-145 双签放行合规平面
### 5.1 核心价值
- 在断连场景下提供本地批准资料包与执行连续性。
- 对高风险任务和 CRS 执行双签要求。
- 通过 Confidential Ledger + WORM 保存不可篡改签署证据。
- 支持远端机坪和机库的弹性运行。
- 提升监管核查和内部审计应答能力。
### 5.2 优势画像
- 在现场连续性和法规可辩护性方面最强。
- 对放行责任边界和证据链治理最稳健。
- 降低因网络波动导致的运行中断风险。
### 5.3 局限性
- 设备、缓存、密钥生命周期治理复杂。
- 同步冲突与延迟上传需要专项运行手册。
- 多站点规模化时运维要求更高。

## 10. 场景 A：机队级排故质量提升
### 10.1 场景背景
- 混合机队运营方在修订版切换期间出现排故检索歧义。
- 航线团队反馈本地资料与批准版本偶发偏差。
- 质量团队要求工卡动作与手册依据形成强关联追溯。
### 10.2 架构决策
- 用平面 A 先把尾号/MSN 效力锁定做硬化。
- 用平面 B 把证据化建议接入结构化工卡执行流。
- 用平面 C 承担放行双签和不可篡改证据沉淀。
### 10.3 量化结果
- `measured`：错误资料引用事件下降 63%。
- `measured`：部分 ATA 章节排故决策时长下降 28%。
- `anonymized_reported`：质量审计准备工时下降 24%。

## 11. 场景 B：AOG 与 MEL 延期协同
### 11.1 场景背景
- 远端站点 AOG 事件存在库存可见性不足和时限追踪偏差。
- MEL 延期类别执行在站点间口径不一致。
- 远端机坪网络波动导致关键时刻资料不可用。
### 11.2 架构决策
- 平面 B 提供确定性 MEL 时限逻辑和全球可换件池可视化。
- 平面 C 提供离线执行能力与延迟同步机制。
- 平面 A 保证高压场景下仍是正确效力资料。
### 11.3 量化结果
- `measured`：AOG 决策到动作中位时长由 96 分钟降至 61 分钟。
- `measured`：参与基地 MEL 逾期事件下降 41%。
- `anonymized_reported`：单事件重复排故循环下降 19%。

## 12. 量化 FAQ
### Q1：效力锁定对排故质量的提升幅度有多大？
试点实测中，错误效力引用事件下降 40% 到 65%。
历史版本治理薄弱的组织提升更明显。
### Q2：MCP 执行层能否减少 MEL 时限错误？
可以。A/B/C/D 确定性逻辑可显著减少误分和逾期风险。
参与站点在时限异常上出现了可观下降。
### Q3：为什么离线边缘在航线维修是刚需？
仅依赖云端会在机坪网络波动时中断关键流程。
离线批准资料包可保障连续作业与安全边界。
### Q4：非例行工卡应如何做关闭治理？
必须要求持证人员检验并完成双签策略要求。
这样可提升审计可辩护性并降低返工率。
### Q5：边缘合规投入何时值得？
在 AOG 成本区间下，只要避免少量长时延误就可覆盖投入。
`synthetic` 100 架机队模型显示回报通常较快显现。
### Q6：不可篡改归档会拖慢放行吗？
会增加少量流程开销，但在合规与追溯收益前通常可接受。
实测环境在吞吐稳定的同时显著提升审计应答效率。

## 17. Good fit / Not for
### Good fit
- 混合机队且合规压力高的航空公司与 MRO 集团。
- 需要放行证据可审计、可辩护的组织。
- 愿意投入确定性控制和离线韧性的团队。
### Not for
- 期望无持证责任人自动放行的场景。
- 缺乏效力元数据和修订治理纪律的环境。
- 不愿运维边缘设备与签名密钥体系的项目。
---
## 18. 推进顺序建议
1. 先做平面 A，优先消除效力与修订错误检索风险。
2. 再做平面 B，把确定性执行和 AOG 协同落地。
3. 最后做平面 C，补齐离线韧性与放行合规治理。
4. 按基地和机队类型分批推广并设置 KPI 门禁。
5. 将合规抽检和模型风险评审制度化。
---
## 19. 最终建议
采用“三平面航空智能体架构”：先保证资料效力正确，再保证执行规则确定性，最后保证放行签署合规性。
该模式可同时提升排故质量、AOG 响应效率和监管可追溯性，并保持明确的人类放行责任边界。
长期效果依赖于严格的人类授权、不可篡改证据和持续治理执行。

## 20. 周度 KPI 评分卡（建议）
- 按机队统计效力不匹配阻断次数与复发趋势。
- 过期修订版检索尝试趋势。
- 按站点/ATA 统计工卡草案采纳率。
- MEL A/B/C/D 时限遵循率。
- AOG 可换件调拨时长分布。
- 校准校验失败数量与闭环时长。
- 离线缓存新鲜度达标率。
- 边缘同步冲突率与中位修复时长。
- CRS 候选任务双签完成及时率。
- 非例行任务检验后复开率。
- 监管抽查证据检索耗时。
- 避免长时 AOG 的单事件价值估算。
- 策略例外积压与老化。
- 季度合规演练通过率。
