7 / 7 · 我的结论

多租户 SaaS 与高合规金融场景具备生产就绪度。

✅ Good fit
  • Coding Agent sandbox: Agent ID + OBO scoped delegation by tool lane
  • Browser/CUA cluster: token minimization with replay guard + private secret path
  • Multi-tenant SaaS gateway: ACL-bound retrieval and tenant-claim contracts
  • Financial zero-trust: Private Link + Key Vault + immutable delegation audit
⛔ Not for
  • Shared long-lived service principal across all agent workers
  • Bypassing Search ACL in retrieval fan-out under burst traffic
  • Public egress Key Vault access for high-risk tenant workloads
  • No replay guard on OBO token exchange
