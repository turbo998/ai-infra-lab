7 / 7 · 我的结论

AKS 多租户公平份额调度方案适合 Agent 集群生产治理与 FinOps 约束。

✅ Good fit
  • Coding Agent sandbox batch + interactive mixed queues with fairness guards
  • Browser/CUA clusters requiring tenant quotas and preemption-safe fallback
  • Multi-tenant SaaS with cohort lending and token-level cost attribution
  • Financial zero-trust requiring strict tenant isolation and deterministic rollback lanes
⛔ Not for
  • GPU sharing without tenant budget caps or quota classes
  • Spot-first strategy without deterministic On-Demand fallback SLO
  • MIG partitioning without workload type matching and QoS policy
  • Preemption enabled without replay/compensation contracts for long jobs
