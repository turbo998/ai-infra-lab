7 / 7 · 我的结论

OTel GenAI 语义约定 + Foundry Tracing + ADX/Grafana 适合生产级多 Agent 可观测性。

✅ Good fit
  • Coding Agent sandbox: per-tool span trace and loop-stop guard with token budget
  • Browser/CUA cluster: correlated spans across UI action lane and tool lane
  • Multi-tenant SaaS gateway: tenant-scoped FinOps attribution with token lineage
  • Financial zero-trust: immutable trace export with policy-enforced evaluation gates
⛔ Not for
  • Trace IDs generated per hop without cross-agent parent context
  • No tenant dimension in token and latency attribution records
  • Offline-only evaluation with no online anomaly trigger path
  • Runaway tool loop detected only by manual dashboard inspection
