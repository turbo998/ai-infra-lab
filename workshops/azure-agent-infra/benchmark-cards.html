7 / 7 · 我的结论

A2A+Streamable-HTTP 双平面拓扑适合企业级多租户 Agent 联邦互操作。

✅ Good fit
  • Coding Agent sandbox federation with explicit Agent Card trust chain
  • Browser/CUA clusters needing streamable-HTTP pool reuse and lower reconnect tax
  • Multi-tenant SaaS gateway with APIM registry governance + tenant custody controls
  • Financial zero-trust requiring east-west mTLS mesh policy and isolated tenant federation
⛔ Not for
  • No agent-card version policy or backward-compatibility contract
  • Connection pooling without per-tenant circuit breakers and token custody
  • Cross-tenant federation enabled without blast-radius boundaries
  • Single-plane topology with no failover between edge-gateway and mesh lanes
