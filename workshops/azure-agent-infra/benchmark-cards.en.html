7 / 7 · MY TAKE

MCP tool-custody attestation architecture fits enterprise zero-trust tool-calling governance.

✅ Good fit
  • Coding Agent sandbox tool calls with signed card verification before execution
  • Browser/CUA clusters requiring policy denials with deterministic audit lineage
  • Multi-tenant SaaS gateway with tenant-scoped policy bundles and key rotation windows
  • Financial zero-trust with immutable tool-custody attestations and HITL overrides
⛔ Not for
  • Unsigned MCP tool cards allowed in production registry
  • No policy bundle version pinning between gateway and sidecars
  • Global key rotation without tenant rollout waves or rollback plan
  • Runtime denials without replay artifacts for post-incident adjudication
