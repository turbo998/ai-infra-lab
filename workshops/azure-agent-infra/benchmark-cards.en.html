Confidential GPU attested enclave architecture fits highly regulated agent inference and custody governance.

✅ Good fit
  • Regulated banking/healthcare agents requiring zero-operator-visibility execution

  • Multi-tenant SaaS needing enclave proof gates per tenant policy tier
  • High-assurance tool-calling agents requiring immutable attestation audit lineage
⛔ Not for
  • Confidential mode enabled without attestation verification enforcement
  • Secure key release configured without policy-bound measurement claims
  • Ignoring TDX/SEV-SNP and Hopper CC overhead in SLO sizing decisions
  • Mixing confidential and non-confidential lanes without custody boundaries
